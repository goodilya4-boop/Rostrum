# Трибуна / Rostrum

«Трибуна» — локальное веб-приложение для репетиции защиты ВКР. Пользователь загружает презентацию, проводит выступление с распознаванием речи и получает отчёт по регламенту, темпу, словам-паразитам и покрытию ключевых тезисов.

## Состояние проекта

Работают:

- регистрация, вход и JWT-авторизация;
- загрузка и разбор PPTX/PDF;
- защищённая выдача изображений слайдов;
- создание и проведение репетиции;
- Web Speech в поддерживаемом браузере;
- сохранение транскриптов и переключений слайдов;
- анализ выступления и страница результатов;
- профиль и пользовательские настройки;
- миграции, транзакции и интеграционные тесты.

Vosk отмечен как **«В разработке»** и отключён для пользователей. Контракт и экспериментальный сервис сохранены для дальнейшей работы, но не считаются готовой функцией.

Docker-конфигурация удалена. Текущий поддерживаемый способ запуска — локальные процессы Node.js и отдельная PostgreSQL.

## Структура

| Каталог | Назначение |
| --- | --- |
| `Rostrum-Backend` | Express API, PostgreSQL, парсинг и анализ |
| `Rostrum-Frontend` | Vue 3, Pinia, Vite и Web Speech |
| `Rostrum-Backend/vosk-service` | Экспериментальная заготовка Vosk, не готовая к использованию |

## Требования

- Node.js 18 или новее;
- npm;
- PostgreSQL;
- Microsoft Edge или другой браузер с рабочим Web Speech;
- LibreOffice и Poppler — необязательно, для нативного рендеринга слайдов.

## Первый запуск

### Backend

```powershell
cd Rostrum-Backend
npm install
Copy-Item .env.example .env
npm run migrate
npm run dev
```

Перед миграцией создайте пустую PostgreSQL-базу и заполните параметры `DB_*` в `Rostrum-Backend/.env`.

Проверка:

```text
http://localhost:3000/api/health
```

### Frontend

Во втором терминале:

```powershell
cd Rostrum-Frontend
npm install
npm run dev
```

Откройте http://localhost:5173 в Microsoft Edge и разрешите доступ к микрофону.

Команды нужно выполнять внутри соответствующего каталога. В корне проекта нет `package.json`, поэтому корневая команда `npm start` не используется.

## Проверка проекта


```powershell

```

## Ограничения

- Vosk пока не готов и недоступен при создании сессии.
- Web Speech зависит от реализации и сетевого сервиса браузера.
- Для Web Speech рекомендуется Edge; встроенный браузер VS Code не подходит.
- Production-развёртывание и CI ещё не зафиксированы как поддерживаемый контур.
- Полные E2E-тесты с настоящим микрофоном и офисным renderer пока отсутствуют.

Подробности находятся в [Backend README](Rostrum-Backend/README.md) и [Frontend README](Rostrum-Frontend/README.md).
