# Rostrum Frontend

Frontend — это интерфейс приложения «Трибуна». Здесь пользователь загружает презентацию, проводит репетицию и смотрит результаты.

## Что работает

- регистрация и вход;
- список и загрузка презентаций;
- просмотр слайдов;
- настройка и проведение репетиции;
- распознавание речи через Web Speech;
- результаты выступления;
- профиль и настройки.

Vosk пока находится в разработке и недоступен.

## Запуск

Сначала запустите Backend на порту `3000`. Затем выполните:

```powershell
npm install
Copy-Item .env.example .env
npm run dev
```

Откройте http://localhost:5173.

Для Web Speech лучше использовать Microsoft Edge. Разрешите браузеру доступ к микрофону. Встроенный браузер редактора кода для этого не подходит.

## Тесты и сборка

```powershell
npm test
npm run build
```

## Основные папки

- `src/pages` — страницы приложения;
- `src/components` — элементы интерфейса;
- `src/api` — запросы к Backend;
- `src/stores` — данные приложения;
- `src/composables` — работа с распознаванием речи;
- `src/assets/styles` — общие стили.
