# Rostrum Frontend

Vue-интерфейс приложения «Трибуна» для загрузки презентаций, проведения репетиций и просмотра результатов.

## Реализовано

- регистрация и вход;
- защищённые маршруты;
- список, загрузка и просмотр презентаций;
- редактирование ключевых тезисов;
- создание репетиции;
- экран выступления с таймером и навигацией;
- Web Speech и отправка финальных сегментов;
- результаты анализа и история;
- профиль и настройки;
- обработка ошибок API и уведомления.

Vosk отображается как **«В разработке»**, отключён в настройках и недоступен при создании репетиции.

## Стек

- Vue 3;
- Vue Router;
- Pinia;
- Axios;
- Vite;
- Vitest и Vue Test Utils.

## Настройка и запуск

```powershell
npm install
Copy-Item .env.example .env
npm run dev
```

По умолчанию приложение открывается на http://localhost:5173, а Vite перенаправляет `/api` на `http://localhost:3000`.

Backend запускается отдельно из каталога `Rostrum-Backend`.

## Web Speech

Рабочий движок распознавания — Web Speech:

1. создайте новую репетицию с движком `Web Speech`;
2. откройте приложение в Microsoft Edge;
3. разрешите доступ к микрофону;
4. нажмите «Включить микрофон»;
5. финальные фразы будут отправляться в Backend.

Web Speech может использовать внешний сервис браузера и требует интернет. Встроенный браузер VS Code и некоторые Chromium-браузеры предоставляют API, но не предоставляют рабочий сервис распознавания.

## Маршруты

| URL | Страница |
| --- | --- |
| `/login` | вход |
| `/register` | регистрация |
| `/dashboard` | обзор |
| `/presentations` | презентации |
| `/presentations/upload` | загрузка |
| `/presentations/:id` | просмотр слайдов |
| `/session/new` | настройка репетиции |
| `/session/:id/rehearsal` | экран выступления |
| `/session/:id/results` | результаты |
| `/settings` | профиль и настройки |

## Хранение состояния

- `auth.store` управляет токеном и пользователем;
- `presentation.store` загружает презентации и слайды;
- `session.store` управляет репетицией, очередями синхронизации и результатами;
- `toast.store` показывает уведомления.

Токен добавляется Axios interceptor. Ответ `401` очищает локальную сессию и переводит пользователя на страницу входа.

Изображения слайдов загружаются как защищённые Blob-ресурсы с JWT, поэтому прямых публичных URL файлов нет.

## Структура

```text
src/
  api/          Axios и модули API
  components/   UI и компоненты предметной области
  composables/  Web Speech и экспериментальный MediaRecorder
  layouts/      общие макеты
  pages/        страницы маршрутов
  router/       маршрутизация и guards
  stores/       Pinia stores
  styles/       глобальные стили
```

## Ограничения

- Vosk пока отключён.
- Web Speech зависит от браузера и сети.
- Production web-server и deployment ещё не стандартизированы.
- Полные E2E-тесты с реальным микрофоном пока отсутствуют.
