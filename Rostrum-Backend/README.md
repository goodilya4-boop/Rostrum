# Rostrum Backend

Backend хранит пользователей, презентации и репетиции, а после выступления составляет отчёт.

## Возможности

- регистрация, вход и профиль;
- загрузка PPTX и PDF;
- создание и завершение репетиций;
- приём текста из Web Speech;
- анализ речи и содержания;
- миграции базы данных;
- защита пользовательских файлов.

Vosk пока не готов и отключён.

## Запуск

Нужны Node.js 18+, npm и PostgreSQL.

```powershell
npm install
Copy-Item .env.example .env
```

Создайте пустую базу PostgreSQL и заполните в `.env` переменные `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER` и `DB_PASSWORD`. Также задайте `JWT_SECRET`.

Подготовьте таблицы и запустите сервер:

```powershell
npm run migrate
npm run dev
```

Backend будет доступен по адресу http://localhost:3000. Проверить его можно здесь:

```text
http://localhost:3000/api/health
```

Для обычного запуска без автоматического перезапуска используется команда:

```powershell
npm start
```

## Презентации

Backend принимает файлы `.pptx` и `.pdf`. Для более качественного создания изображений можно установить LibreOffice и Poppler. Без них сервер создаст простое SVG-превью.

Загруженные файлы закрыты от посторонних пользователей и выдаются только через API.

## Тесты

```powershell
npm test
```

## Основные папки

- `src/controllers` — принимает запросы;
- `src/routes` — адреса API;
- `src/services` — основная логика;
- `src/models` — работа с базой;
- `src/db` — схема и миграции;
- `test` — тесты.
