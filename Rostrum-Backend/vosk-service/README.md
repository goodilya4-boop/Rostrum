# Vosk service — в разработке

Каталог содержит экспериментальный FastAPI-сервис для будущего локального распознавания речи.

Предполагаемый контракт:

- `GET /health` — состояние сервиса и модели;
- `POST /v1/transcribe` — автономный аудиочанк;
- ответ содержит нормализованные сегменты `start_ms`, `end_ms`, `text` и `confidence`.

Сервис пока не входит в поддерживаемый контур проекта:

- автоматическая установка модели отсутствует;
- совместимая среда Python не зафиксирована;
- системная зависимость FFmpeg не устанавливается проектом;
- нет обязательных E2E-тестов с настоящим аудио;
- Frontend и Backend принудительно сообщают `Vosk: В разработке`.

Файлы `app.py` и `requirements.txt` сохранены как основа следующего этапа. Не используйте этот сервис для пользовательских репетиций до снятия перечисленных ограничений.
